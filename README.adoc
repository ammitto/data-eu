= Ammitto EU financial sanctions data

image:https://github.com/ammitto/data-eu/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-eu/actions/workflows/fetch.yml"]

This repository stores the European Union's consolidated financial sanctions
list as YAML for Ammitto. The records in `processed/` cover the persons,
groups and entities listed by the European Commission.

== Source

* Publisher: European Commission, Directorate-General for Financial Stability, Financial Services and Capital Markets Union (DG FISMA)
* Dataset page: https://data.europa.eu/data/datasets/consolidated-list-of-persons-groups-and-entities-subject-to-eu-financial-sanctions?locale=en
* File downloaded (XML, version 1.1): https://webgate.ec.europa.eu/fsd/fsf/public/files/xmlFullSanctionsList_1_1/content?token=dG9rZW4tMjAxNw

The list consolidates the persons, groups and entities subject to EU
financial sanctions, with the legal acts that list them.

== Contents

`processed/` holds one file per listing, named after its EU reference
number: `processed/eu-10012-1.yaml` is `EU.10012.1`.

`processed/_index.yaml` lists every file, with the time of the last fetch.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `eu_reference_number` | string | EU reference number, such as `EU.10012.1`
| `logical_id` | string | Identifier of the entry in the EU XML
| `subject_type` | map | `code` (`person` or `enterprise`) and `classification_code` (`P` or `E`)
| `regulations` | list | Legal acts behind the listing: `regulation_type`, `organisation_type`, `publication_date`, `entry_into_force_date`, `number_title`, `programme` (such as `UKR`, `IRN` or `SYR`) and `publication_url` (EUR-Lex)
| `name_aliases` | list | Names: `whole_name`, and where given `first_name`, `middle_name`, `last_name`, `title`, `function`, `gender`, `name_language`, plus `strong` (true or false)
| `birthdates` | list | Dates and places of birth: `birthdate`, `year`, `month_of_year`, `day_of_month`, `circa`, `year_range_from`, `year_range_to`, `city`, `place`, `region`, `country_iso2_code`, `country_description`, `calendar_type`
| `citizenships` | list | `country_iso2_code` and `country_description`
| `addresses` | list | `street`, `city`, `zip_code`, `region`, `country_iso2_code`, `country_description`
| `identifications` | list | Documents: `identification_type_code` (such as `passport`, `regnumber` or `taxid`), `number`, `country_iso2_code`
| `remark` | string | Remarks published with the listing
| `designation_details` | string | Designation details, where given
| `united_nation_id` | string | UN reference number, for listings that implement a UN designation
|===

Entries in `name_aliases`, `birthdates`, `citizenships`, `addresses` and
`identifications` also carry their own `logical_id`, `regulation_language`
and `regulation_summaries`: the legal act each detail comes from.

`downloaded/eu-data.xml` and `update.log` are older files that the daily
fetch no longer updates; use `processed/`.

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/eu-*.yaml").sort.each do |path|
  record = YAML.safe_load_file(path)
  name = record["name_aliases"].first["whole_name"]
  programmes = record["regulations"].map { |r| r["programme"] }.uniq.join(",")
  puts [record["eu_reference_number"], record["subject_type"]["code"], programmes, name].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("processed/eu-*.yaml")):
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    name = record["name_aliases"][0]["whole_name"]
    programmes = ",".join(sorted({r["programme"] for r in record["regulations"]}))
    print(record["eu_reference_number"], record["subject_type"]["code"], programmes, name, sep="\t")
----

The same list, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/eu.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 06:15 UTC and commits any change to `processed/`. It runs with
`--prune`, so a listing the EU has removed is deleted here on the next fetch.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.3 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch eu --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/eu[`lib/ammitto/sources/eu/`].
Report data or source-list issues in
https://github.com/ammitto/data-eu/issues[this repository].
